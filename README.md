# Simple Linear Model (NumPy)

This project implements a simple linear regression model from scratch using NumPy.  
The goal is to demonstrate how a basic learning algorithm trains using gradient descent.

## Model Description
The model learns a relationship of the form:

y = wx + b

where:
- w is the weight
- b is the bias

Training is done using Mean Squared Error (MSE) loss and gradient descent.

## Training Output
Epoch 0, Loss: 44.0000
Epoch 10, Loss: 0.2435
Epoch 20, Loss: 0.0430
Epoch 30, Loss: 0.0393
Epoch 40, Loss: 0.0367
Prediction for x=6: 11.712485492964916 

## Interpretation
- The decreasing loss shows that the model is learning.
- The final prediction is close to the expected value (12), confirming successful training.
